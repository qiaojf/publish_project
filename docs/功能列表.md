项目部署现状：
前端：需要配置 nginx 代理

   配置nginx代理的内容：（pub.u88.pub这个域名是当前nginx配置默认的例子，暂时可以用来跑通整个流程，后续替换为公司自己的域名）
   1. 把正式 tbpub.conf 的前端目录改成： root /home/user/tbpub/html;
   2. 确认公网入口访问 pub.u88.pub 时，保留 Host pub.u88.pub 并让它命中这个 server：（tbpub.conf server_name增加 pub.u88.pub）
      server {
         listen 80;
         server_name pub.u88.pub tbpub.terabox.co.jp;
         ...
      }

后端： 142 后端服务器连接不上

   可能原因：
   1. 后端142 机器没有启动、
   2. 网卡没有连接
   3. 后端 142 已经不再使用142这个 IP

数据库： 暂未开始部署

   可以现在开始部署，需要连接143服务器。登陆时需要帮忙输入用户名和密码。
   另外部署数据库服务，设置数据库服务开机启动，可能也会用到管理员权限

解决方案：
   1. 请管理员处理前端和后端服务器问题。
   2. 我这边处理，执行部分命令时，需要帮忙输入密码，或者以管理员权限登录，再执行相关命令。可能会需要多次




# 1. 备份现有配置
cp /etc/nginx/conf.d/tbpub.conf \
   /etc/nginx/conf.d/tbpub.conf.bak_20260914

# 2. 使用我们已经准备好的新配置
cp /home/user/tbpub/tbpub.conf.new \
   /etc/nginx/conf.d/tbpub.conf

# 3. 确认配置内容
grep -nE "server_name|root|proxy_pass" \
   /etc/nginx/conf.d/tbpub.conf

# 4. 检查 Nginx 配置
/usr/sbin/nginx -t

# 5. 如果上一步显示 syntax is ok / test is successful，再 reload
systemctl reload nginx

# 6. 在服务器本机验证 tbpub 配置
curl -I -H "Host: pub.u88.pub" http://127.0.0.1
