terabox内容发布平台--功能点梳理

1. 登录（身份认证）
   - 管理员
   - 普通员工

2. 用户管理（权限管理）
   - 新增
   - 修改
   - 禁用
   - 删除
   - 缺少部门
   

3. 内容管理（内容发表）
   - 上传
   - 编辑
   - 删除
   - 查看
   - 分类
   - 提交预发布

4. 自动发布（这里需要更明确的信息，如github，OneDrive，Dropbox，server等）
   - 根据内容类型自动处理
   - 自动发布到对应目录
   - 自动生成URL
   - 发布失败提示
   - 重新发布

5. 内容检索（检索）
   - 关键词
   - 类型
   - 分类
   - 日期

6. 内容查看
   - HTML
   - PPT
   - PDF
   - Word
   - Excel
   - 图片 / 文件

7. 日志（log）
   - 操作日志
   - 发布日志

8. 审核（审查）
   - 审核通过
   - 审核不通过
